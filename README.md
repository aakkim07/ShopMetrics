# ShopMetrics – Analýza cien

## Description
ShopMetrics is a Python desktop application designed for product price analysis and discount calculation.

## Technologies
- Python
- Tkinter
- Random
- Statistics
- Math

## Main Features
- Generation of 50 random product prices.
- Calculation of minimum, maximum and average prices.
- Calculation of a 20% discount.
- Display of customer savings.
- Graphical comparison of original and discounted prices.
- Input validation.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python main.py
```
